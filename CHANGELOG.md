# Changelog

## [v0.3.0](https://github.com/babarot/xxsv/compare/v0.2.0...v0.3.0) - 2026-11-27
### New Features
- Add Notion-like filters with and/or groups by @babarot in https://github.com/babarot/xxsv/pull/13
### Improvements
- Show file names instead of full paths in image cells by @babarot in https://github.com/babarot/xxsv/pull/15
- Show faceted counts in the filter value list by @babarot in https://github.com/babarot/xxsv/pull/16

## [v0.2.0](https://github.com/babarot/xxsv/compare/v0.1.0...v0.2.0) - 2026-11-25
### New Features
- Show image thumbnails in cells by @babarot in https://github.com/babarot/xxsv/pull/8
- Copy selected cells to the clipboard by @babarot in https://github.com/babarot/xxsv/pull/10
- Support LTSV by @babarot in https://github.com/babarot/xxsv/pull/11
- Read web server log times as datetimes by @babarot in https://github.com/babarot/xxsv/pull/12

## [v0.1.0](https://github.com/babarot/xxsv/commits/v0.1.0) - 2026-11-22
### New Features
- Sort by several columns, and hide and move columns by @babarot in https://github.com/babarot/xxsv/pull/5
- Export the current view, and list a column's values by @babarot in https://github.com/babarot/xxsv/pull/6
- Show a row, and search with regular expressions by @babarot in https://github.com/babarot/xxsv/pull/7
### Improvements
- Start faster on large files by @babarot in https://github.com/babarot/xxsv/pull/4
